## Qoder、Qoder CN、通义灵码，到底什么关系？

三个名字指向同一条产品线的不同阶段，这也是目前最容易让人迷糊的地方。

2023 年 11 月，阿里云和通义实验室推出通义灵码，后来它成为国内用户量最大的 AI 编码工具。2025 年 8 月，阿里在此基础上发布了面向全球的 Qoder 平台；2026 年 5 月的 Qoder 1.0 把它从 AI IDE 升级为 Agentic 自主开发工作台；到 2026 年 8 月，桌面端正式改名 Qoder IDE，国内版同步改名 Qoder CN IDE。所以 Qoder CN 并非又一个新产品，它就是通义灵码升级并入 Qoder 体系之后的名字。

产品形态有三种，按使用习惯挑：AI-Native IDE（图形界面）、CLI（终端里跑，`npm install -g @qoder-ai/qodercli`）、JetBrains 插件。顺带提醒，别把 QoderWork 和 QoderWake 混进来——前者是办公产品（2026 年 7 月并入了 Qwen Office 体系），后者是所谓“AI 员工”，都跟写代码的工具分属不同产品。

## 核心能力：仓库级理解和任务式执行

Qoder 的设计思路可以概括为“仓库级理解 + 任务式执行”，拆开看主要是这几块：

- **Repo Wiki**：自动分析代码库并生成结构化文档，官方标注支持最多 10 万个文件的仓库分析。它解决的是接手老项目没人给你讲架构的问题。
- Quest 模式和 Quest Remote：把需求写成 Spec 后交给 Agent 执行，复杂耗时的任务可以一键丢进云端沙箱异步跑，不用盯着本地等结果。
- Experts 模式：2026 年 3 月上线，由一个 Leader Agent 拆解任务，多个专门调优的 SWE Agent 并行干活，覆盖规划、编码、测试到质检。
- 自主 Agent 单次任务最长可执行 26 小时，配合 Next 的 Tab 补全和 Agentic Chat，从行级补全到端到端交付的场景都覆盖。

开放性方面，Qoder 支持 MCP 外部工具协议，CLI 支持自定义插件、自定义命令和 Sub Agent，企业还能拿到专属的 Plugin 和 Skill 市场。语言上，JavaScript、TypeScript、Python、Go、C/C++、C#、Java 有深度支持，主流语言基本都能用。

## 想省 Credits？把 Token Plan 的额度接进 Qoder CN

Qoder CN 支持自带密钥（BYOK），可以把阿里云百炼 Token Plan 的专属 API Key 接进来，让部分调用走 Token Plan 的额度。这套组合适合两类人：一个订阅要喂多个工具的，以及想按模型灵活切换的。

Token Plan 是百炼的大模型订阅服务，同样用 Credits 计量：个人版 Standard 套餐 139 元/月，每 7 天发放 10000 Credits，支持 3-4 个 Agent 并发，可以调 Qwen3.8-Max、DeepSeek-V4、GLM 等多种模型。它还有个夜间优惠：22:00 到次日 8:00 调用指定旗舰模型，Credits 五折，适合夜里挂批量任务。

接入以 IDE 为例：设置 → 模型 → 添加，提供商选“阿里云百炼-国内”，类型选“Token Plan 个人版”，选好模型后粘贴 Key；JetBrains 插件在设置 → 插件设置里添加模型；CLI 用 `/model` 命令切到 Custom 再添加。两个坑必须记住：

1. 配置完成后必须手动切换到 Custom 模型，不切的话系统照旧消耗 Qoder CN 自带的 Credits，Token Plan 等于白买。
2. Token Plan 的专属 Key 以 `sk-sp-` 开头，和百炼通用的按量付费 Key 是两套体系，混用会直接按量扣费而不是抵扣套餐额度。

选型可以这样分：只在 IDE 里写代码 → 59 元的 Pro 就够了，没必要折腾 API；还要写脚本、跑自动化、对比不同模型 → Token Plan 的灵活度更高，两者可以并存。
